# Paradise Nursery - Online Plant Shop

Paradise Nursery is an interactive React-based e-commerce application for plant enthusiasts. Users can browse a wide selection of houseplants categorized by type, add items to a shopping cart using Redux Toolkit, manage quantities, and see dynamic pricing updates in real time.

## Features
- Dynamic landing page with call-to-action button
- Categorized product listing (Aromatic, Medicinal, Air Purifying)
- Interactive Redux Toolkit state management for shopping cart operations
- Real-time item count badges and total cost calculation
- Dynamic item quantity adjustment and item removal
